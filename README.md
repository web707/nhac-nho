# Web Nhắc Nhở Bản Thân

Trang web nhỏ nhẹ nhàng nhắc nhở việc học tập, uống nước và đi ngủ đúng giờ.

## Tính năng
- Đồng hồ thời gian thực và lời chúc theo từng buổi trong ngày.
- Danh sách việc cần làm trong ngày (To-do list) có lưu trạng thái (Local Storage).
- Đếm ngược đến giờ đi ngủ có thể tùy chỉnh.
- Hiệu ứng pháo hoa khi hoàn thành nhiệm vụ.
- Bức thư nhắc nhở cuối ngày.
